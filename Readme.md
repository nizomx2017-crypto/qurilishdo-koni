# Qurilishdo‘koni

Qurilish va sanoat materiallari uchun o‘quv internet-do‘kon loyihasi.

## Loyiha haqida

Qurilishdo‘koni qurilish va sanoat materiallarini onlayn ko‘rish hamda buyurtma qilishga mo‘ljallangan internet-do‘konning o‘quv loyihasidir. Loyiha hozir tahlil va hujjatlashtirish bosqichida.

## Loyihaning maqsadi

MVPda foydalanuvchi katalogdan mahsulot topishi, uni savatchaga qo‘shishi va buyurtma berishi kerak. Administrator esa kategoriya, mahsulot va buyurtmalarni boshqaradi.

## Asosiy imkoniyatlar

- Ro‘yxatdan o‘tish va tizimga kirish.
- Kategoriya va mahsulotlar katalogi, mahsulot nomi bo‘yicha qidiruv.
- Savatchaga mahsulot qo‘shish, miqdorini o‘zgartirish va o‘chirish.
- Buyurtma berish hamda foydalanuvchi buyurtmalarini ko‘rish.
- Administrator tomonidan kategoriya va mahsulotlarni qo‘shish, tahrirlash va o‘chirish.
- Administrator uchun buyurtmalar ro‘yxati.

## Loyiha strukturasi

- `code/` — keyingi bosqichda yoziladigan dastur kodi.
- `configs/` — keyingi bosqichdagi loyiha sozlama fayllari.
- `docs/` — umumiy, frontend va backend hujjatlari.
- `tahlil/` — MVP tahlili va ish ketma-ketligi.

## Texnologiyalar

Aniq texnologiyalar hali tanlanmagan. Tanlov boshlovchi uchun sodda bo‘lishi, Python, Java yoki JavaScript muhitida ishlashi, ma’lumotlar bazasini qo‘llashi va frontend bilan API orqali ulanishi ko‘zda tutilgan.

## Ishga tushirish

Hozircha ishga tushiriladigan dastur kodi mavjud emas. Avval talablar va texnologiyalar tasdiqlanadi, so‘ng interfeys, autentifikatsiya, katalog, savatcha hamda buyurtmalar bosqichma-bosqich ishlab chiqiladi.

# Arxitektura

Bu hujjat ilovaning asosiy qismlarini ko‘rsatadi.

- Frontend — User va Admin uchun veb sahifalar (React + Vite, `code/frontend/`).
- Backend — autentifikatsiya, katalog, savatcha va buyurtmalar qoidalari (Node.js + Express REST API, `code/backend/`).
- Ma’lumotlar bazasi — foydalanuvchi, kategoriya, mahsulot, savatcha va buyurtma ma’lumotlari (PostgreSQL, `code/database/`).

Frontend backend bilan faqat REST API (JSON) orqali ulanadi. Texnologiyalar bo‘yicha qaror: [08-texnologik-qarorlar.md](08-texnologik-qarorlar.md).

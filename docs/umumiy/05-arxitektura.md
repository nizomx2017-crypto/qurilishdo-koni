# Arxitektura

Bu hujjat ilovaning asosiy qismlarini ko‘rsatadi.

- Frontend — User va Admin uchun veb sahifalar.
- Backend — autentifikatsiya, katalog, savatcha va buyurtmalar qoidalari.
- Ma’lumotlar bazasi — foydalanuvchi, kategoriya, mahsulot, savatcha va buyurtma ma’lumotlari.

Texnologiyalar kod yozish bosqichidan oldin alohida tasdiqlanadi.

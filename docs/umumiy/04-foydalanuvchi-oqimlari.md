# Foydalanuvchi oqimlari

Bu hujjat MVPdagi asosiy harakatlar ketma-ketligini tushuntiradi.

1. User ro‘yxatdan o‘tadi yoki login qiladi.
2. Katalogdan kategoriya yoki qidiruv orqali mahsulot topadi.
3. Mahsulotni savatchaga qo‘shadi va buyurtmani tasdiqlaydi.
4. User o‘z buyurtmalarini ko‘radi.
5. Admin kategoriya va mahsulotlarni boshqaradi, buyurtmalarni ko‘radi.

# Texnologik qarorlar

Bu hujjat texnologiyalarni tanlashdan oldin e’tiborga olinadigan mezonlarni saqlaydi.

Tanlov boshlovchi uchun sodda bo‘lishi, Python, Java yoki JavaScript muhitida ishlashi, ma’lumotlar bazasini qo‘llashi va frontend bilan API orqali ulanishi kerak. Aniq texnologiyalar keyingi qarorda tanlanadi.

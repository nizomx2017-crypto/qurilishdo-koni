# Texnologik qarorlar

Bu hujjat texnologiyalarni tanlash mezonlari va tasdiqlangan stekni saqlaydi.

Mezonlar: tanlov boshlovchi uchun sodda bo‘lishi, Python, Java yoki JavaScript muhitida ishlashi, ma’lumotlar bazasini qo‘llashi va frontend bilan API orqali ulanishi kerak.

Tasdiqlangan stek:

- Frontend: React + Vite, `react-router`, oddiy CSS.
- Backend: Node.js + Express, JWT autentifikatsiya, `helmet`, `express-rate-limit`.
- Ma’lumotlar bazasi: PostgreSQL (lokal yoki Supabase).
- Deploy: backend — Render, frontend — Vercel, baza — Supabase.

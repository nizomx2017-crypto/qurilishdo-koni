# Qabul mezonlari

- User ro‘yxatdan o‘tishi va login qilishi mumkin.

- User savatchani boshqarib, buyurtma beradi va o‘z buyurtmalarini ko‘radi.
- Admin kategoriya va mahsulotlarni boshqaradi, barcha buyurtmalarni ko‘radi.

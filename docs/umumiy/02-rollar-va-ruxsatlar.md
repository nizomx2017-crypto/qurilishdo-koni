# Rollar va ruxsatlar

Bu hujjat MVPdagi foydalanuvchi huquqlarini belgilaydi.

- `User` — ro‘yxatdan o‘tadi, mahsulotlarni qidiradi, savatchani boshqaradi va o‘z buyurtmalarini ko‘radi.
- `Admin` — User huquqlariga qo‘shimcha ravishda kategoriya va mahsulotlarni boshqaradi hamda barcha buyurtmalarni ko‘radi.
